# Portfolio assets

Create these folders and add your own media files:

- `assets/videos/` for MP4 and WebM projects
- `assets/thumbnails/` for optional video poster images
- `assets/audio/` for optional ambient audio

Then add the matching paths to `SITE_CONTENT` in the root `script.js`.

No sound effects are included. Ambient audio is optional and requires a visitor to press the audio control.
